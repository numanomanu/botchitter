# ボッチッター (botchitter)

> **自分にしか見えないタイムライン。**  
> 誰にも見られず、誰も邪魔しない。思考と感情を淡々と残すための完全ローカル完結型 PWA。

- **Web App:** https://botchitter.vercel.app
- **License:** [MIT License](LICENSE)

## コンセプト・背景

### 逆転した時間観：未来 → 現在 → 過去
一般的には時間は「過去 → 現在 → 未来」へ流れていると考えられます。  
しかし、このプロダクトの根底には **「時間は未来から現在、そして過去へと流れているのではないか」** という時間観があります。

- **未来** には、世界や自分自身の大きな流れがすでに兆候として存在している。
- **現在** において、人間はその流れの中で目の前に現れる小さな選択肢を選びながら生きている。
- **過去** は出来事そのものは変えられなくても、その **「意味」** は現在からいくらでも変えられる（「あの時の失敗が、すべての始まりだった」と思えるように）。

### 「意味のない点」を残す
このアプリにおける記録は、普通の日記や目標管理ではありません。  
今という時間の中に見つけた **「点」** をただ残すこと。

記録する時点で「何のために」「どういう意味があるか」を分類させたり、解釈させたりしません。  
時間が経ち、過去の記録を見返したとき、あるいは引用したときに初めて、バラバラだった点が一本の線になります。

> **点 → 点 → 線**  
> 過去の自分が見ていた未来に、あとから出会う。

### なぜ「自分専用のタイムライン」なのか
1. **言葉を削ぎ落とした静けさ**  
   「今日、何が見えた？」といった問いかけや説明的なUIは、思考の邪魔になる。日常の道具として徹底的に淡々としていること。
2. **過去の思考を上書きしない**  
   過去のメモを編集して上書きしてしまうと、当時の定点観測が消えてしまう。Twitterのように「投稿・返信・引用」の制約があるからこそ、思考のログが歪まずに残る。
3. **完全なプライベート空間**  
   他人の反応や「いいね」を気にするSNSでは、本当の思考や未整理の感情は書けない。サーバー通信を行わず、端末の IndexedDB にのみ保存される閉じた空間だからこそ、自分自身と純粋に対話できる。

## 主な機能

- **完全ローカル保存**: データは端末内の IndexedDB にのみ保存。外部サーバーへの送信なし。
- **一人タイムライン**: 思考の点を時系列で記録。返信（スレッド）、引用、編集履歴に対応。
- **振り返り（草カレンダー）**: 投稿数と5段階の気分をヒートマップで可視化。過去の記録を辿るビュー。
- **タグ & 全文検索**: `#タグ` のインラインハイライト、リアルタイムインクリメンタル検索。
- **リンクプレビュー**: 本文中の URL からタイトルを取得・カード表示（SSRF対策・自前プロキシ経由）。
- **端末間の同期（QR）**: PC で書いた分をスマホへ。送る側の画面に出した QR を、受け取る側のアプリ内カメラで読むだけ。サーバーは使わない。前回送ってから書いた・直した・消した分だけを送り、新しい方の編集を採用する（両方で直していた場合も、負けた方は編集履歴に残る）。
- **バックアップ**: JSON での書き出し・読み込み（同期と同じ混ぜ方。全体の引っ越し用）。
- **PWA 完全対応**: オフライン動作、ホーム画面追加による全画面ネイティブアプリ化。
- **ダークモード**: OS 連動および手動切り替え対応。

> **iOS (Safari) でのご利用について**  
> Safari のタブのままだと、長期間アクセスがない場合にブラウザの仕様でデータが消去される場合があります。 **「ホーム画面に追加」** してご利用ください。

## 技術構成

フレームワークやビルドツールは一切使用していません。素の HTML/CSS/JavaScript のみで構成されています。外部ライブラリは同期で QR を作る・読むための2つだけで、`vendor/` に同梱しています（CDN から読まない）。リンクタイトル取得 API（`api/ogp.js`）だけは、内部ネットワーク宛ての接続を防ぐために npm の `undici` を使います（`package.json`）。

```
├── index.html        # マークアップ・PWA設定
├── style.css         # 共通スタイル・変数・レイアウト
├── compose.css/js    # 投稿フォーム・タグハイライト・気分選択
├── timeline.css/js   # タイムライン描画・カード・日付区切り
├── detail.css/js     # 詳細ビュー・スレッド・編集履歴
├── archive.css/js    # 振り返り（草ヒートマップ・アニメーション）
├── search.css/js     # 全文検索
├── sync.css/js       # 端末間の同期（QR で送る・受け取る）
├── vendor/           # qrcode-generator（MIT）・jsQR（Apache-2.0）
├── storage.js        # IndexedDB 永続化・バックアップ
├── data.js           # 初期シードデータ・定数
├── i18n.js           # 多言語リソース（日/英）
├── sw.js             # Service Worker（オフラインキャッシュ）
└── api/ogp.js        # リンクタイトル取得 API（Vercel Function）
```

### ローカル起動

```bash
python3 -m http.server 3333
```
ブラウザで `http://localhost:3333` を開きます。
